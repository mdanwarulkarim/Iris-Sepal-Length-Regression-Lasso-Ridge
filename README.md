# Iris-Sepal-Length-Regression-Lasso-Ridge
This repository provides a comparative regression analysis on the classic Iris dataset. The goal is to predict **Sepal Length (cm)** using the remaining measurements (*sepal width*, *petal length*, and *petal width*) using standard Ordinary Least Squares (OLS) Linear Regression, Ridge ($L_2$) Regression, and Lasso ($L_1$) Regression.
